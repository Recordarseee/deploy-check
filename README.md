# JSON 工具

一个单文件的 JSON 格式化小工具，纯前端、零依赖、零构建。

**在线使用**：<https://recordarseee.github.io/deploy-check/>

## 能做什么

| 功能 | 说明 |
|---|---|
| 格式化 | 2 空格 / 4 空格 / Tab 缩进 |
| 压缩 | 去掉所有空白，输出最小体积 |
| 键排序 | 递归按字母序重排对象键，方便对比两份 JSON |
| 校验 | 解析失败时给出行号、列号 |
| 复制 | 一键复制结果 |
| 结果回填 | 把结果移回输入框，继续连续处理 |

快捷键：`Ctrl + Enter` 格式化（Mac 是 `Cmd + Enter`）。

## 特点

- **数据不出本机** —— 所有解析都在浏览器里做，没有任何请求
- **单文件** —— 整个应用就是一个 `index.html`，没有依赖、没有构建步骤
- **自动统计** —— 实时显示行数、字节数、以及格式化省下了多少体积

## 本地打开

直接双击 `index.html` 就行，不需要服务器。

## 部署

```powershell
.\deploy.ps1 "改了什么"
```

推上去后 GitHub Pages 会在 30-60 秒内自动重建。
